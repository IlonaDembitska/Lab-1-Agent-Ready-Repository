# Відкот зміни кроку 02

Зміна: `parse()` повертає `null` для нескінченних чисел (`Infinity`, `-Infinity`) замість того, щоб пропускати їх без змін — `index.js:142`, `!isNaN(val)` → `Number.isFinite(val)`.

## 1. План (заповнено ДО першого рядка коду, дата: 2026-11-12)

- Обраний шлях: **git revert**
- Чому саме він: зміна — один рядок в одному файлі реалізації й один коміт; revert не додає залежностей, не змінює API і не лишає в чужому проєкті нічого мого. Прапорець (flags / @openfeature/server-sdk) означав би нову залежність у бібліотеці з нулем залежностей; конфігурація через змінну середовища — новий публічний перемикач у бібліотеці, яка конфігурації не читає взагалі.
- Команда дослівно (на окремій гілці-доказі):
  ```
  git switch -c lab4/rollback-drill lab4/change
  git revert --no-edit <sha коміта зміни>
  ```
  SHA коміта зміни буде відомий після коміту; відкочується **рівно один** коміт — коміт зміни (`fix:`), **не** коміт нового тесту.
- Ознака, що відкот потрібен:
  - будь-який тест проєкту (`test/byte-format.js`, `test/byte-parse.js`, `test/bytes.js`) або мій характеризаційний тест, крім двох свідомо оновлених тверджень про `Infinity`/`-Infinity`, падає після зміни (`npm test` → код ≠ 0);
  - або користувач бібліотеки повідомляє, що спирався на `parse(Infinity) === Infinity` (наприклад, як на «безліміт» у налаштуваннях розміру).
- Чого відкот НЕ повертає: нічого зайвого — зміна не чіпає `package.json`, lock-файла немає, нових файлів реалізації немає. Новий тестовий файл (`test/parse-non-finite.js`) лежить в окремому коміті **перед** зміною, тому revert його **не** видаляє — після відкоту він має стати червоним.
- Скільки це займає: ~1 хв (одна команда revert + прогін тестів ~1 с).
- Як перевірю, що відкот спрацював:
  - характеризаційні + тести проєкту: `npx mocha --check-leaks test/byte-format.js test/byte-parse.js test/bytes.js test/characterization-parse.js` → код **0**;
  - новий тест: `npx mocha --check-leaks test/parse-non-finite.js` → код **≠ 0** (червоний), файл на місці: `test -f test/parse-non-finite.js`;
  - `git log --oneline -5` показує і `fix:`, і `Revert "fix: …"`.
