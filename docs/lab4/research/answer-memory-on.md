# Дослідження (memory-on)

**Питання:** Чому parse('0x11') повертає 0, а не 17, і чому для рядка без одиниці функція parse досі бере parseInt, а не відкидає невалідний вхід?

Функція parse повертає 0 для рядка '0x11' через навмисну поведінку, яка перевірена тестом проєкту та закріплює припущення про байти без одиниць. Для таких вхідних даних використовується вбудований parseInt, оскільки регулярний вираз не містить літери b для їх відсікання.

1. Тест 'Should assume bytes when no units' закріплює поведінку bytes.parse('0x11') через перевірку assert.equal(bytes.parse('0x11'), 0);
