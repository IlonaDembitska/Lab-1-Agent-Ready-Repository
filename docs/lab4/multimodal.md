## Роль у продукті

- **Що саме робить мультимодальний шлях:** асистент ПДР з Лаби 2 приймає фото/скан сторінки або PDF (конспект, договір автошколи, специфікація) і відповідає на питання за цим файлом — для PDF з номером сторінки у форматі `[стор. N]`; відповідь можна **прослухати** (кнопка «Озвучити відповідь» → `generateSpeech`) — для учнів, які повторюють теорію голосом.
- **Що застосунок робить, коли файл непридатний:**
  - тип поза білим списком (TIFF, Word тощо) → у браузері: «Файл не надіслано: тип … не підтримується; можна: PNG, JPEG, WEBP, HEIC, PDF»; якщо запит прийшов не з форми — сервер **415** `reason: mediaType`, модель не викликається;
  - заявлений тип не збігається з вмістом (PNG під виглядом PDF) → **415** `reason: mismatch` (перевірка за сигнатурою байтів, не за розширенням);
  - файл понад 3 MB → у браузері дружня відмова до надсилання; запит не з форми 3–4,5 MB → сервер **413** `reason: size`; понад 4,5 MB → **413 `FUNCTION_PAYLOAD_TOO_LARGE` від платформи**, наш код не виконується;
  - файл нечитабельний або відповіді в ньому немає → модель відповідає «не знаю» (інструкція в промпті; перевірено випадками mm-04, mm-05).

## Генерація зображень — поза межами, і чому

Безкоштовного шляху до генерації зображень у джерелах курсу не підтверджено в жодного провайдера: у всіх перевірених моделей зображень Google у колонці Free Tier стоїть «Not available». `generateImage` в ai@7 існує і НЕ є експериментальною, але прогнати її за нуль неможливо. Тому крок будується на вході (зображення, PDF) плюс мовленні.

## Вхід

- Частина повідомлення: **`FilePart`** — `{ type: 'file', mediaType, filename, data: { type: 'data', data: bytes } }` (`src/multimodal/ask.ts`), `mediaType` обов'язковий. Застарілої `ImagePart` (`{ type: 'image' }`) у коді немає.
- Форма data: **`{ type: 'data' }` — сирі байти**. Чому: файли ≤ 3 MB, браузер шле їх у `multipart/form-data`, функція має байти в пам'яті — посилання (`url`) чи `uploadFile`/`reference` тут лише додали б запит. Для файлів понад ліміт правильний шлях — Files API + `{ type: 'reference' }` (див. «обхід» у таблиці меж); у цьому кроці не реалізовано, такі файли відхиляються.
- Медіатип: заявлений клієнтом **перевіряється** сигнатурою байтів (`sniffMediaType` у `limits.ts`: PNG, JPEG, PDF, WEBP, TIFF, HEIC) — розширення файлу не використовується взагалі.
- Білий список медіатипів: `image/png`, `image/jpeg`, `image/webp`, `image/heic`, `image/heif`, `application/pdf`.
- Модель: **`gemini-3.5-flash-lite`** (`CATALOG` у `src/models.ts`), безкоштовний рівень.

## Вихід

- Функція: **`generateSpeech`** (НЕ експериментальна; `experimental_generateSpeech` — застарілий аліас) для озвучення відповіді; **`transcribe`** — лише для перевірки round-trip у наборі.
- Моделі: **`gemini-3.8-flash-tts`** і **`gemini-3.5-transcribe`** — «Free of charge».
- `voice` / `outputFormat` / `language` **не задавала**: допустимих значень у перевірених джерелах немає. Подивилась результат очима (траса `docs/lab4/traces/multimodal-mm-11.json`): без цих параметрів модель повертає **`audio/wav`** (174 792 Б для англійського речення, 261 520 Б для українського); поле результату — `res.audio` з `uint8Array` і `mediaType` (взято з типу в редакторі, `tsc --noEmit` без помилок).

|---|---|---|---|
| розмір запиту | 20 MB інлайн (увесь запит) | 4,5 MB тіло → 413 `FUNCTION_PAYLOAD_TOO_LARGE` | браузер не надсилає файл > 3 MB і пише чому; сервер відповідає 413 `size` на 3–4,5 MB; > 4,5 MB — 413 платформи (**перевірено в продакшні, mm-09**) |
| PDF | 50 MB або 1000 стор.; 258 токенів/стор.; файли Files API живуть 48 год | 4,5 MB | ті самі 3 MB; великий PDF — лише через Files API (не реалізовано, відмова) |
| зображення | до 3 600 файлів на запит; PNG/JPEG/WEBP/HEIC/HEIF; 258 токенів (≤ 384 px) або плитки 768×768 по 258 | 4,5 MB | білий список = перелік Gemini без HEIF-варіацій поза ним; TIFF → 415 до моделі (**mm-08**) |
| аудіо | 9,5 год; 32 токени/с | 300 с → 504 `FUNCTION_INVOCATION_TIMEOUT` | аудіо на вхід не приймається; вихід TTS — коротка відповідь (≤ 1000 символів), `maxDuration = 60` с на маршрут |
| обхід | Files API: 20 GB/проєкт, 2 GB/файл, 48 год, «available at no cost» | — | документований шлях повз 4,5 MB; у цьому кроці не реалізовано |
| журнали | — | журнали прогону Hobby — 1 година | розбір — за власними трасами в `docs/lab4/traces/` і Langfuse |

**Мій клієнтський ліміт: 3 000 000 байтів** (`MAX_BYTES` у `src/multimodal/limits.ts`, одна константа для браузера й сервера). Нижче за 4,5 MB з запасом: файл іде в `multipart/form-data` сирими байтами, але навіть у разі base64 (+≈⅓) 3 MB → ~4 MB < 4,5 MB (перевіряє тест).

**Розбіжність у документації, яку я не вирішую:** сторінка Files API радить її при запитах понад 100 MB і згадує 50 MB для PDF, а сторінки зображень і аудіо називають 20 MB сумарно. Безпечною інлайн-стелею вважаю 20 MB; на практиці моя стеля однаково 4,5 MB тіла функції.
