# MCP-сервер — специфікація v1

Статус: v1, 2026-10-14 — записано ДО коду сервера. Методичка на цю дату ще не дає технології для кроку 08 («план»); технологію обрано самостійно — якщо курс задасть іншу, специфікацію буде переглянуто окремим комітом. Рішення про інструменти й застосунок — моє (spec.md, розділ 9).

## Технологія
- Сервер: офіційний TypeScript SDK протоколу MCP — @modelcontextprotocol/sdk 1.32.1 (McpServer + StdioServerTransport).
- Транспорт: stdio — клієнт запускає сервер як локальний процес (npx tsx scripts/mcp-server.ts); мережевого порту немає.
- Логіка — чиста функція src/mcp/search-pdr.ts (тести без мережі); scripts/mcp-server.ts лише реєструє її в SDK.
- У stdout нічого не друкується (там протокол) — діагностика лише в stderr.

## Інструмент search_pdr
- Що робить: гібридний пошук по ПДР (вектор + BM25 → RRF, код кроку 05, індекс v2), повертає фрагменти з даними для цитування.
- Вхід: query — рядок 1–300 символів (пробіли на краях обрізаються); k — ціле 1–5, типово 5. Інших полів немає.
- Вихід (успіх): текст із JSON-масивом до k обʼєктів { chunkId, docId, heading, start, end, text } у порядку ранжування.
- Вихід (відмова): isError: true і причина українською; сервер не падає.
- Залежності: data/index.json (у git), локальна Ollama з embeddinggemma-2:270m.

## Межі (чого інструмент не робить ніколи)
- Лише читає data/index.json: не відкриває інших файлів, не приймає шляхів, не пише на диск.
- Не повертає більше 5 фрагментів і не повертає документ цілком.
- Не викликає мовну модель і не ходить у мережу, крім локальної Ollama.
- Не виконує текст запиту як інструкцію.
